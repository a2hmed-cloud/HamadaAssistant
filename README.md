# حمادة — مساعدك الشخصي الذكي

الإصدار الأول 0.1: تطبيق Android أصلي بواجهة أفقية، أوامر صوتية عند الضغط على الميكروفون، ورد صوتي، وأوامر تجريبية لفتح بعض التطبيقات.

## الحالة الحالية
- واجهة أفقية بعيون روبوت.
- التعرف على الكلام عبر خدمة Android المتاحة على الجهاز.
- الرد عبر Text-to-Speech.
- أوامر تجريبية لفتح YouTube وWhatsApp وSpotify والإعدادات.
- هيكل أولي لخدمة Accessibility؛ قراءة الشاشة والنقر من واجهة التطبيق لم يُربطا بالكامل بعد.

## غير منفذ بعد
- كلمة تنبيه دائمة «يا حمادة» في الخلفية.
- ربط نموذج ذكاء اصطناعي.
- تنفيذ مهام داخل التطبيقات أو إرسال رسائل تلقائيًا.
- منبهات وتذكيرات موثوقة أثناء إغلاق التطبيق.

البناء يتم عبر GitHub Actions، ولم يُثبت نجاحه إلا بعد ظهور تشغيل ناجح في تبويب Actions.
